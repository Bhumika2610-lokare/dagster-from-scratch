# Day 6.5 Challenges - Error Handling

## Challenge 1

Create a Safe Age Checker.

Ask user for age.

Rules:

- Age cannot be negative.
- Age must be a number.

Example:

Input:

25

Output:

Valid Age

---

Input:

abc

Output:

Invalid Input

---

Input:

-5

Output:

Age Cannot Be Negative

---

## Challenge 2

Create a Safe Division Calculator.

Ask:

- Number 1
- Number 2

Calculate:

Number1 ÷ Number2

Handle:

- Invalid numbers
- Division by zero

Example:

Input:

10
0

Output:

Cannot Divide By Zero

---

## Challenge 3

Create a Safe Student Marks Calculator.

Ask marks.

Rules:

- Marks must be numbers
- Marks must be between 0 and 100

Examples:

95 ✅

101 ❌

-10 ❌

abc ❌
