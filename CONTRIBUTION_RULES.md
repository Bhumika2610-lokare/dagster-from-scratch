# 📋 Contribution Rules

Before contributing, please read these rules carefully.

---

# ✅ What You Can Add

## Documentation

You can:

- Improve README files
- Add better explanations
- Fix grammar mistakes
- Add diagrams
- Add learning notes

Example:

✅ Add examples for SQL queries

✅ Explain concepts in simple English

✅ Add step-by-step instructions

---

## Challenges

You can add:

- Beginner Challenges
- Intermediate Challenges
- Bonus Challenges

Example:

```text
Challenge 1
Challenge 2
Challenge 3
Bonus Challenge
```

---

## Test Cases

You can add:

- Positive Test Cases
- Negative Test Cases
- Edge Cases

Example:

```text
Input: 100
Expected: Success
```

---

## Code Improvements

You can:

- Improve readability
- Add comments
- Improve variable names
- Add validation
- Improve error handling

Example:

✅ Replace:

```python
x = 100
```

with

```python
total_sales = 100
```

---

## New Learning Resources

You can add:

- Notes
- Cheat Sheets
- Practice Questions
- Interview Questions

---

# ❌ What You Should NOT Add

## No AI Generated Spam

Do not add:

```text
asdfasdf
test
hello world
random files
```

---

## No Unrelated Projects

Do NOT add:

```text
React Projects
Java Projects
Gaming Projects
Crypto Projects
```

This repository is only for:

```text
Python
SQL
ETL
Data Engineering
Dagster
```

---

## No Huge Libraries

Do not commit:

```text
venv/
node_modules/
dist/
build/
```

---

## No Secrets

Never commit:

```text
Passwords
API Keys
Tokens
Database Credentials
```

Example:

❌

```python
password = "admin123"
```

---

## No Breaking Existing Code

Do not:

- Delete folders
- Rename folders without discussion
- Remove documentation

---

## No Low Quality Commits

Bad Examples:

```bash
git commit -m "update"
```

```bash
git commit -m "changes"
```

```bash
git commit -m "test"
```

Good Examples:

```bash
git commit -m "Day 15: Added SQL filtering examples"
```

```bash
git commit -m "Docs: Improved Day 10 explanations"
```

```bash
git commit -m "Fix: Corrected Day 7 grading logic"
```

---

# 📂 Folder Standard

Every learning day should contain:

```text
day-xx-topic/

README.md
main.py
challenge.md
test_cases.md
```

Example:

```text
day-10-encapsulation-atm/

README.md
atm_system.py
challenge.md
test_cases.md
```

# ✅ Golden Rule

Ask yourself:

"Will this help a beginner learn?"

If YES ✅

Contribute it.

If NO ❌

Do not add it.
