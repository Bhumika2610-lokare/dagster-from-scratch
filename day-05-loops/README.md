## What is a Loop?

A loop repeats code multiple times.

Example:

```python
for i in range(5):
    print(i)
```

Output:

```text
0
1
2
3
4
```

---

## What is a List?

A list stores multiple values.

Example:

```python
expenses = [100, 200, 300]
```
