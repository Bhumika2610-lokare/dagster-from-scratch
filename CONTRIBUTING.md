# 🤝 Contributing to Dagster From Scratch

Thank you for contributing!

This repository documents a learning journey from Python Beginner → Data Engineer → Dagster Engineer.

---

## Before You Start

### 1. Fork the Repository

Click the **Fork** button on GitHub.

This creates your own copy of the project.

---

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR_USERNAME/dagster-from-scratch.git
```

Go into the project folder:

```bash
cd dagster-from-scratch
```

---

### 3. Create a New Branch

Always create a new branch before making changes.

```bash
git checkout -b feature/day-15-improvements
```

Example branch names:

```text
feature/readme-update
feature/sql-notes
feature/challenges
bugfix/typo-fix
```

---

## Making Changes

### Follow Repository Structure

Every day folder should contain:

```text
day-xx-topic/
│
├── README.md
├── main.py
├── challenge.md
└── test_cases.md
```

Example:

```text
day-08-student-database/
│
├── README.md
├── student_database.py
├── challenge.md
└── test_cases.md
```

---

### Add Documentation

Whenever possible:

✅ Explain the concept

✅ Add examples

✅ Add test cases

✅ Add challenges

---

## Commit Rules

Write meaningful commit messages.

✅ Good

```bash
git commit -m "Day 15: Added SQL filtering examples"
```

```bash
git commit -m "Docs: Improved Day 10 notes"
```

```bash
git commit -m "Fix: Corrected Day 6 test cases"
```

❌ Bad

```bash
git commit -m "update"
```

```bash
git commit -m "changes"
```

```bash
git commit -m "test"
```

---

## Push Changes

```bash
git add .

git commit -m "Your commit message"

git push origin your-branch-name
```

---

## Create a Pull Request

After pushing:

1. Open GitHub
2. Open your fork
3. Click **Compare & Pull Request**
4. Add a short description
5. Submit the Pull Request
