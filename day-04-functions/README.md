## What is a Function?

A function is a reusable block of code.

Example:

```python
def greet():
    print("Hello")
```

Call it:

```python
greet()
```

Output:

```text
Hello
```

---

## Why Functions?

Without Functions:

```python
print("Hello")
print("Hello")
print("Hello")
```

With Function:

```python
def greet():
    print("Hello")

greet()
greet()
greet()
```

Cleaner ✅
