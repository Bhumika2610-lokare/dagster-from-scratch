## What is Encapsulation?

Encapsulation means:

Protecting data and controlling access.

Example:

Balance should not be modified directly.

---

## Private Variables

```python
self.__balance
```

Double underscore makes the variable private.

---

## Public Methods

```python
deposit()
withdraw()
show_balance()
```

These methods interact with balance safely.
