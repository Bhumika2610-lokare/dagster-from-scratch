# Day 17 Challenges

Try these using `main.sql` in SQLite Online (https://sqliteonline.com/).
Use the same `students` table already set up in `main.sql`.

## Challenge 1: Count Students by Grade
Write a query that shows how many students there are for each grade
value (9, 10, 8, etc).

## Challenge 2: Find the Section With the Highest Average
Write a query that shows each section along with its average grade,
sorted so the highest average appears first.

## Challenge 3: Sections With More Than 1 Student
Write a query that only shows sections that have more than 1 student
in them.

## Challenge 4: Total and Average Together
Write one query that shows, for each section: the number of students,
their total combined grade, and their average grade — all three in the
same row.

## Bonus Challenge ⭐: Give Your Columns Names
Rewrite Challenge 4 so the output columns are labeled clearly, using
`AS`, like `student_count`, `total_grade`, and `average_grade`, instead
of showing up as `COUNT(*)` and `SUM(grade)`.
